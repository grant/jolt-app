# jolt-app

A simple Mac app wrapper around app.usejolt.ai.

## Installation

Install deps:

```bash
npm install
```

Build:

```bash
npm run build
```

Open the zip:

> Your folder path may vary depending on your OS.

```bash
open dist/jolt-desktop-1.0.0-arm64-mac.zip
```

Copy app to Applications:

```bash
cp -r dist/jolt-desktop.app /Applications/Jolt.app
```

Open Jolt.app in Applications:

```bash
open /Applications/Jolt.app
```

Login and Voila!
